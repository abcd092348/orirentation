# Robotics & AI Orientation Experience

An interactive, responsive educational website introducing robotics,
artificial intelligence, engineering, and student learning.

## Designed By

Muhammad Usman Akram

## Features

- Cinematic welcome page
- Interactive three-slide introduction
- Robotics and AI overview
- Machine learning introduction
- Sensors and embedded systems
- Computer vision overview
- Student learning journey
- Technology image gallery
- Responsive mobile navigation
- Scroll animations
- Optional audio support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Structure

- `index.html` — Welcome page
- `intro.html` — Introduction slides
- `orientation.html` — Main orientation website
- `css/` — Website styling
- `js/` — Website interactions
- `assets/` — Optional local media

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Make sure the `css` and `js` folders remain in the same locations.

## Publish on GitHub Pages

1. Upload all project files to a GitHub repository.
2. Open the repository's Settings.
3. Select Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for deployment to finish.

The published website starts at `index.html`.

## Media

The default image links use Unsplash. An internet connection is
required to load these images.

Optional audio can be added at `assets/sound.mp3`.
